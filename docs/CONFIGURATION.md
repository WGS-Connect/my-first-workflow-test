# Configuration

Primary non-secret settings live in `config/channels.yaml`.

Important audiobook defaults:

- target duration: 60 minutes
- 130 words/minute
- reusable backgrounds: `assets/audiobook/backgrounds`
- people: `assets/audiobook/persons`
- music: `assets/audiobook/music`
- thumbnail templates: `assets/audiobook/thumbnails`
- scene geometry: `assets/audiobook/scene.yaml`
- voice selection: `config/voice_settings.txt`
